[[ADR-CLOUD-001]]
== ADR-CLOUD-001: Use a shared event-driven cloud foundation

Status:: accepted
Date:: 2026-09-19

=== Context

Product services need consistent resilience and observability.

=== Decision

Publish event ingestion and managed runtime as a reusable module.

=== Consequences

- Products share operational controls while retaining separate data domains.

[[DEC-TIER-MVP]]
== DEC-TIER-MVP: shared cloud platform runs at the mvp tier with the foundation bundle

Status:: accepted
Date:: 2026-11-12

=== Context

The example is a complete model at one stated tier so that the required lifecycle switches (ADR-EMG-061) are met and its generated artifacts show the diagnostics of that tier.

=== Decision

Tier: MVP
Bundles: foundation
The example declares lifecycle tier mvp with requirementLinks strict and lintRun mode strict.

=== Consequences

- The strict requirement link rules apply from the mvp tier.
- The tier rules of mvp key the severity of the example's findings.
