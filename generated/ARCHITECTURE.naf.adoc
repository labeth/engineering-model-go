= Engineering Model Go NAF 4.1 Architecture Description
:naf-framework: NATO Architecture Framework
:naf-version: 4.1
:engmod-model-id: engineering-model-go

This architecture description applies NAF 4.1 profile metadata to canonical Engineering Model views.
Architecture elements and relationships remain defined once in the canonical SysML/KerML-aligned semantic model.

== Stakeholders

[cols="1,2,3",options="header"]
|===
|Actor ID |Stakeholder |Role
|`ACT-ARCHITECTURE-AUTHOR` |Architecture Author |Owns architecture scope, viewpoints, and model decisions.
|`ACT-COMPLIANCE-ENGINEER` |Compliance Engineer |Uses correspondence and evidence views for assurance.
|`ACT-IMPLEMENTATION-ENGINEER` |Implementation Engineer |Uses architecture products to implement and assess change impact.
|===

== Concerns

[cols="1,2,4,3",options="header"]
|===
|Concern ID |Name |Description |Stakeholders
|`NAF-CONCERN-ARCHITECTURE-COVERAGE` |Architecture coverage |The architecture must communicate model responsibilities and generated products. |ACT-ARCHITECTURE-AUTHOR, ACT-IMPLEMENTATION-ENGINEER
|`NAF-CONCERN-LIFECYCLE` |Generation lifecycle |Model changes must progress through validation and deterministic artifact generation. |ACT-ARCHITECTURE-AUTHOR, ACT-IMPLEMENTATION-ENGINEER
|`NAF-CONCERN-TRACEABILITY` |Architecture correspondence |Requirements, implementation ownership, and verification evidence must remain traceable. |ACT-ARCHITECTURE-AUTHOR, ACT-COMPLIANCE-ENGINEER
|===
